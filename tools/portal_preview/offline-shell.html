Offline preparation tools

Keep your essentials

Save it. Reopen it. Keep working.

  1. Keep this HTML file in a folder you can find. Open it with a current desktop web browser, even when disconnected.
  2. Use Save collection JSON, Save source plan, Save bounds file or the CSV buttons to keep your work. Keep your original GPX and map images alongside it.
  3. Next time, reopen this page and choose those files again. Images, routes, places and selections are not embedded in this page or saved automatically.

On a phone or tablet, a file preview may not run these tools. Use a browser that can open local HTML with JavaScript, or transfer the file to a computer.

What comes with this file

  • 53-region source planner and transfer estimates
  • GPX trace, elevation and waypoint inspection
  • PNG, JPEG and still WebP map viewing
  • GeoJSON vector layers and vertex inspection
  • Saved-place collection with CSV / GPX exchange
  • Saved-plan and calibrated-coordinate exports
  • Printable coordinate sheets with optional distance / true-bearing estimates

Map datasets, knowledge packs, the full FieldForge application, sign-in and chat are not included. These tools do not calculate driving directions. Correct image coordinates require bounds and projection that you supply.

Source sizes are estimates from October 4, 2026. Open the portal when online to get a newer copy of these tools. Downloading an update does not transfer files already open in this tab.
